# science-writing

> 把学术知识转译成通俗、可信、让人记得住的科普文章——不牺牲因果机制和模型自觉。

---

## 一句话定位

这是一个 **带护栏的科普写作工作流**。它解决了科学写作中最隐蔽的陷阱：**修辞对概念的殖民**——拟人化替换因果机制，比喻替换物理图像，故事替换历史证据，文学升华替换模型自觉。

通俗化很容易，准确也很容易，**通俗且准确**很难。这套技能把这种张力变成了可管理的工程问题。

---

## 核心理念

科普的通俗化不能以牺牲以下四条为代价：

- **因果机制** → 不被拟人化或目的论替换
- **物理图像** → 不被不兼容的比喻堆叠淹没
- **历史证据** → 不被未经证实的轶事偷梁换柱
- **模型自觉** → 不被浪漫化为事物的灵魂

用一句话说：**好科普靠信息密度取胜，不靠修辞堆砌。**

## 使用方式

### 交互模式（默认）

向 AI 提出科普写作需求，例如：

- 帮我写一篇关于 CRISPR 基因编辑的科普
- 把这篇论文讲给高中生听
- 用大白话解释量子纠缠

AI 会在 **Phase 1** 确认需求（主题、目标读者、篇幅、素材情况），**Phase 3** 初稿完成后暂停请用户确认方向，确认后再进入润色与交付。

### 自主模式

当 AI Agent 直接执行且无人交互时，自动使用默认值：

- 目标读者 = 受过基础科学教育的普通成年人
- 篇幅 = 中等（1500–4000 字）
- 素材 = 自行检索权威信源
- 交付 = 单篇终稿 + QA 自检报告（一气呵成，不中途停顿）

## 核心规则速览

### 8 条修辞防殖民准则（必守）

| # | 规则 | 核心要求 |
|---|------|---------|
| 1 | 拟人化禁令 | 不把系统写成有意图、会选择的主体 |
| 2 | 目的论禁令 | 不把结果伪装成动机（禁止为了……所以……） |
| 3 | 比喻管控 | 单一比喻体系 + 标注失效边界 |
| 4 | 模型实体化禁令 | 理论模型是表征工具，不是物理实在 |
| 5 | 历史叙事审慎 | 区分有据史实与未经证实的轶事 |
| 6 | 定量参照系 | 每个数值必须提供数量级坐标（统计题材另加 4 条） |
| 7 | 结尾模型自觉 | 不许把理论模型升格为灵魂或本质 |
| 8 | 修辞克制 | 内容密度优先于修辞密度 |


### 13 条写作实操准则

包括：术语剥离优先、增量推进、逻辑铺陈、主次分明、有机组织、闭环论证、正反对照、意外转折、具象锚点、渗透式升华、数字参照系、信源标注、模型自觉。


### 19 项自查清单

Phase 5 交付前逐条核查，涵盖：

- 结构与内容（5 项）
- 修辞防殖民（8 项）
- 公式、单位与数据（3 项）
- 终稿精修预检（3 项）

所有检查通过后方可交付。

## 信源标准

**优先级**（从高到低）：
1. 一手学术文献（期刊论文、预印本）
2. 权威学术期刊的综述文章
3. 权威媒体的深度报道（Nature News、Scientific American 等）
4. 一般媒体报道（仅作现象存在佐证）

**黑名单（不采信）**：
- 微信公众号、百家号、头条号、搜狐号、网易号等自媒体聚合平台
- 缺乏作者署名或无编辑审核机制的转载站
- 问答类平台（百度知道、知乎回答等）UGC 内容
- SEO 农场与内容农场站点

## 产出物规范

每篇终稿统一包含四部分：

1. **标题**
2. **正文**（按题材适配骨架：原理解释型 / 误区纠正型 / 历史叙事型 / 机制拆解型 / 统计解读型）
3. **核心记忆点**（1–2 句，读者应能复述的要点）
4. **信源与延伸阅读**（按等级 1–4 标注，附作者/标题/出处/年份）

同时附一份 **QA 自检报告**，逐项说明 19 项自查结果，保证交付透明可追溯。

| 适用 | 不适用 |

| 科学普及 / 大众科学解读 | 小说 / 诗歌创作 |
| 论文转译给外行读者 | 新闻报道 |
| 用大白话解释专业概念 | 纯翻译（无转译与重构） |
| 面向公众的课题成果传播 | K12 教材编写 |
